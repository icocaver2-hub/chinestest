# 追加教材を生成するプロンプト

別の対話や生成ツールで使い、出力をJSONファイルとして手動で取り込む。アプリから外部APIへ接続する処理は不要。

## 使用前に指定するもの

- テーマ: 例「ご両親との食事」「結婚の挨拶」「春節の帰省」。
- packIdと新規IDの接頭辞: 他の教材と重複しない英小文字・数字・ハイフン。
- レベル: beginner / elementary / intermediate。
- 問題数と形式別の内訳。
- 既存教材更新なら、その教材のJSONと現在のrevision。

生成する相手に[教材仕様](../docs/05_CONTENT_FORMAT.md)、[会話教材計画](../docs/10_SCENARIO_CONTENT.md)、[サンプル](../examples/starter-pack.json)を添付または全文貼り付ける。リンクだけで読めると仮定しない。

## 貼り付ける指示

```text
日本語話者が、パートナーのご家族と普通話で会話するための学習教材を作成してください。
添付する教材JSON契約v1、会話教材計画、サンプルJSONの形式を厳守してください。

今回の条件:
- テーマ: <テーマ>
- packId: <一意のパックID>
- IDの接頭辞: <重複しない接頭辞>
- 難易度: beginner
- シーン数: 1
- 会話: 4発言以上。learnerとpartnerの両方を含める
- 重要表現: 6件以上
- 問題数: 8（single_choice 4、ordering 2、fill_blank 2）
- 音声: なし

内容の条件:
1. 普通話・簡体字・声調記号付きピンインを使い、日本語訳・解説を付ける。
2. 中国語、ピンイン、訳、正解、解説の対応を点検する。軽声は無記号、「一」「不」の一般的な変調は読みを示し、第三声連続は辞書表記にする。
3. ご両親への丁寧で自然な会話を扱い、相づち・聞き返し・質問への返答も含める。
4. 結婚の場面では二人の意思を尊重した表現にし、家庭の習慣を普遍的と断定しない。
5. 実在の人の氏名、職業、収入、住所、結婚予定を推測しない。
6. 中国語検定・HSKの出題形式を参考にしてよいが、過去問を転載せずオリジナル問題にする。級の同等性を断定しない。
7. 選択問題は正解が1つになるようにする。並べ替えは自然な別順序もacceptedOrdersへ登録する。穴埋めは許容別解をacceptedAnswersに含める。
8. 問題の正解全文に対応したpinyinとtranslationを付ける。

形式の条件:
1. schemaVersionは1。packId、title、scenarios、questionsを必ず含める。
2. 新規項目のrevisionは1。既存を修正する場合はIDを保ちrevisionを増やす。
3. すべてのscenarioIdが同じJSON内のシーン、または明示的に渡した既存シーンを参照するようにする。
4. IDは英小文字・数字・ハイフン・アンダースコアのみ、1〜80文字。
5. 未指定の任意項目は省略し、nullを入れない。
6. 音声なしのためaudioAssets、audioId、presentation、transcriptを省略する。音声のURLや架空のファイルを生成しない。
7. 添付契約に存在しないフィールドを追加しない。
8. 出力はJSONオブジェクトのみ。Markdownのコードフェンス、前置き、説明文、コメントは付けない。

出力前に、JSONとしての妥当性、ID重複、正解ID、並べ替えトークン、空欄の数、参照先、中国語と訳の整合性を確認してください。
```

## 取り込み後の確認

JSONとして保存し、教材画面で差分・本文・解説を確認する。文法的な正確さは形式検査だけでは保証されない。問題を見つけたら対象IDを保ってrevisionを増やした修正版を生成する。別パックを作るときは新しいIDを使う。

既存シーンに問題だけ追加する場合、scenariosは空配列でよい。そのシーンが登録済みであることと、追加する問題IDが未使用であることを確認する。
