## 初期教材の点検記録（2026-11-13）

対象: `public/content/core-family.json`（6シーン・発言55・重要表現46・置き換え例18・問題48）。

- 全発言・表現・置き換え例・問題について、中国語・ピンイン・日本語訳の対応を1件ずつ目視で確認した。問題は正解の全文とpinyin・translationが一致することも確認した。
- ピンインの表記方針: 声調記号を使い、軽声は無記号（例: xièxie、shūshu、kèqi）。「一」「不」は実際の読み（yí biàn、yìdiǎnr、yì jiā、bú tài、búcuò、bù hǎoyìsi）。第三声の連続は辞書の声調（hěn hǎochī、Wǒ xǐhuan）。儿化は表記どおり（yìdiǎnr、wánr、hǎohāor）。
- 選択式は正解が1つになるよう誤答を選び、誤答の意味を解説に書いた（例: 好吃／好喝／好看）。
- 許容別解: 並べ替えは「平时」の位置（first-meeting-q6）と話題の前置き（marriage-q6）で2通りを正解とした。穴埋めは「尝尝／尝一尝／尝一下」「有点儿／有点」「明白／知道／懂」を許容した。
- 呼び方（叔叔・阿姨）、手土産、食べ残し、結婚の挨拶の手順は家庭によって違う旨を補足に書き、普遍的と断定しない表現にした。
- 実在の人名・地名・結婚の時期・住む場所などは入れていない。未定のことは「还在商量」で答える練習にした。
- 中国語検定・HSKの過去問は使っていない（すべてオリジナル）。級の同等性は示していない。
- 限界: 作成者自身による点検であり、中国語ネイティブ話者による確認は未実施。不自然な点が見つかったら、IDを保ったままrevisionを上げて修正する。
