# 画面・操作設計

## 共通

モバイルでは「ホーム / 会話 / 問題 / 復習 / 教材」の5ナビゲーションを表示する。設定と履歴はホーム・教材画面から開く。中国語本文は十分な大きさにし、ピンイン・訳は本文の近くに配置する。

採点の色だけで正誤を伝えない。ボタンはタッチ操作に十分なサイズを確保する。音声は自動再生しない。回答の正解・訳・ピンインが答えを漏らす場合は解答後に表示する。

## ホーム

- 「今日の学習を始める」、今日の回答数、復習予定数、未克服の苦手問題数。
- 記録は問題の自動採点と会話の自己評価を分けて表示。
- 中断した学習がある場合は再開/終了して新規開始を選べる。
- 初回は目的、1日の問題数、表示設定を短い説明で設定できる。入力を必須にしすぎない。
- 復習も未学習もない場合は、場面別会話と任意の問題演習に誘導する。

## シチュエーション一覧・詳細

カテゴリ/難易度で絞り込み。カードには名称、目標、関連問題数、音声有無を表示する。

詳細は「場面と目標 → 会話例 → 重要表現 → 置き換え例 → 補足 → 関連問題」の順。会話例は話者、中国語、ピンイン、訳を表示し、訳とピンインを隠せる。

会話練習では相手の発言を表示し、自分の返答を考えてから例を開く。「言えた / 少し迷った / 言えなかった」を保存する。自己評価は問題正答率に加算しない。

## 問題演習

開始前にテーマ、形式、難易度、問題数を選ぶ。1問ずつ出題し、回答確定後に正誤・正解・解説・ピンイン・訳を表示する。

- 選択式: 1つの選択肢を選ぶ。未選択で送信不可。
- 並べ替え: 単語タイルをタップして組み立てる。削除/戻す/やり直し可能。ドラッグ専用にしない。
- 穴埋め: 1つの解答入力欄。中国語IMEの変換確定で誤送信しない。
- 音声付き: 再生、停止/一時停止、再生速度。読み込み/非対応形式のエラーを表示する。
- ブックマークは回答前後で操作可能。

不正解は演習末尾の再挑戦キューに入る。再挑戦は各問題1回までとし、無限に終了しない演習を防ぐ。結果には初回正答率と再挑戦結果を分けて表示する。

終了時に回答数、初回正答率、苦手問題、次の復習予定を表示する。中断しても保存済みの回答は残る。教材更新で古いセッションが無効になった場合は、その旨を案内し新しい問題で開始する。

## 復習

「今日の復習 / 前回不正解 / 繰り返し間違える / ブックマーク」の切り替え。場面・タグ・難易度で絞る。「克服済みも表示」を用意する。

各問題には累計不正解数、最新結果、復習日、克服状態を表示。任意の問題を選ぶか、絞り込み結果をまとめて演習できる。詳細ルールは06を使う。

## 教材・設定

教材の一覧、JSON選択、音声選択、プレビュー、取り込み実行、取り込み履歴を用意する。履歴には日時・ファイル名・件数を残す。

プレビューは「新規 / 更新 / 変更なし / 古いrevision / エラー」を区別し、更新対象の旧/新本文を見比べられる。エラーは`questions[2].answerId`のように位置を示す。キャンセルでDBを変更しない。

設定は1日の問題数（5〜30、既定10）、ピンイン/訳の表示、学習タイムゾーン、バックアップ書き出し、復元、任意の永続ストレージ要求を扱う。タイムゾーン変更時は過去の学習日を再計算しないと明示する。

## バックアップ復元

ファイル選択 → 全件検査 → 現在と復元後の件数表示 → 現在データの書き出し導線 → 置き換えて復元。教材追加と復元を別操作にし、通常の教材取り込みで履歴を消せないようにする。

## 空・異常状態

検索結果0件、音声未収録、音声ファイル不足、教材不正、保存領域不足、初回オフライン、DB不可、未知のURL、復元の非対応バージョンを個別に扱う。空の一覧を障害と見せず、次にできる操作を提示する。
