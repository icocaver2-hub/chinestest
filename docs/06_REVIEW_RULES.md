# 採点後の記録・復習ルール

## 用語

- 通常回答: 演習/復習でその問題に最初に答えた回答。
- 即時再挑戦: 不正解になった同一演習の末尾で行う1回の再回答。
- 学習日: `occurredAt`を設定のIANAタイムゾーンで日付化したYYYY-MM-DD。既定Asia/Tokyo。
- 復習連続正解日数: 期限到来後の正解を、異なる学習日ごとに1回だけ積み上げた値。

## 保存する状態（問題ID + revision単位）

`attemptCount`、`incorrectCount`、`lastResult`、`lastAttemptAt`、`nextReviewDate`（null可）、`reviewSuccessDays`、`lastCreditedDate`（null可）、`lastIncorrectDate`（null可）、`mastered`。

`attemptCount`と`incorrectCount`には即時再挑戦も含める。初回正答率は別途通常回答のみで集計する。現在のrevisionだけを出題し、旧revisionの履歴は保存する。

## すべての回答に共通する更新

一意なsubmissionIdで重複を防ぎ、履歴追加と状態更新を同じDBトランザクションで行う。

1. 回答回数、最新結果、最新日時を更新。
2. 不正解なら不正解回数を加算し、連続正解日数を0、克服済みをfalse、復習日を翌日、lastIncorrectDateを今日へ更新する。lastCreditedDateは保持する。
3. 正解時は以下の表を適用する。

| 状態 | 正解時の処理 |
| --- | --- |
| 未学習の通常回答 | 復習日を翌日。連続正解日数は0 |
| 即時再挑戦 | 最新結果のみ正解にする。復習日・連続正解日数・克服状態を進めない |
| 期限前の任意演習 | 復習日・連続正解日数・克服状態を進めない |
| 今日すでに正解日数に算入済み、または今日不正解あり | 復習日・連続正解日数・克服状態を進めない |
| 期限到来（復習日≦今日）の通常回答、上記除外なし | 連続正解日数を1加算し、lastCreditedDateを今日にする |

期限到来で加算した後の間隔:

| 復習連続正解日数 | 次回 | 克服状態 |
| --- | --- | --- |
| 1 | 今日から3日後 | false |
| 2 | 今日から7日後 | false |
| 3以上 | 今日から14日後 | true |

克服後も14日間隔の復習を続ける。不正解になれば再び翌日からやり直す。今日不正解の後に同日正解しても翌日の復習を残す。翌日以降なら通常回答として評価できる。

日付の加算はカレンダー日で計算し、ミリ秒で24時間を足す実装にしない。夏時間のあるタイムゾーンでも日付を正しく扱う。

## 一覧の条件

- 今日の復習: nextReviewDateが今日以前。
- 前回不正解: lastResultがincorrect。再挑戦で正解すればここから外れるが、復習予定は残る。
- 繰り返し間違える: incorrectCount≧3、かつmastered=false。
- 克服済みも表示: incorrectCount≧3の全問題を表示。UIに状態を示す。

## 今日の学習の選び方

1. 期限到来の復習から、未克服かつ不正解3回以上 → その他の順。
2. 各グループは復習予定日の古い順、同日ならID順。
3. 設定問題数に満たなければ未学習問題を教材の登録順・ID順で加える。
4. 対象が不足すれば少ない件数で開始し、未来の復習を自動で前倒ししない。
5. 即時再挑戦は設定問題数の外枠として最大で各1回追加する。

## 例

10月23日に不正解 → 即時再挑戦で正解しても10月24日が復習日。10月24日の復習正解で10月27日、10月27日の正解で11月3日、11月3日の正解で克服済み・11月17日が次回になる。

同じ日に10回正解しても復習連続正解日数を10にしない。期限前の正解は復習日を延ばさない。どの画面から答えても、期限到来などの条件が同じなら同じ判定を行う。
